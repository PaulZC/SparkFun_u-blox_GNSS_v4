◆ init() [1/2]

bool SparkFun_UBLOX_GNSS::SfeI2C::init ( TwoWire & wirePort,
uint8_t address,
bool bInit = false )

Initialize this I2C bus using a caller-supplied Wire port.

The address is always (re-)applied, even if this object was already initialized, so a caller can change the module's I2C address without re-constructing the bus object.

Parameters
wirePortThe TwoWire (Wire) instance to use.
addressThe 7-bit I2C address of the GNSS module.
bInitIf true, also call wirePort.begin(). Defaults to false (caller already began it).
Returns
true on success.
