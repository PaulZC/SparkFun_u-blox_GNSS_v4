void ubxMessageRegistry::registerMessage ( ubxMessageFactoryFn factory)
inline

Register one message class's factory function, if not already registered.

Called by each ubxMessageBuilder<MessageType> at static-initialization time. De-duplicates by function-pointer value, so a header included from multiple translation units still ends up registered exactly once - see the file-level comment above for why.

Parameters
factoryFunction that constructs one instance of the message class being registered.
