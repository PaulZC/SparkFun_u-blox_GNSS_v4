Get the number of bytes currently available to read from this bus.

For Serial, this is Serial.available(). For I2C, this reads the module's 0xFD/0xFE byte-count registers. Not applicable for SPI (always returns 0).

◆ ping()

virtual bool SparkFun_UBLOX_GNSS::GNSSDeviceBus::ping ( )
pure virtual

Check whether a GNSS module is present/responding on this bus.

Meaningful for I2C only (sends an address-only transmission and checks for an ACK); SPI and Serial cannot detect presence this way and their overrides simply return false.

Returns
true if a device responded, false otherwise (or if not applicable to this bus).

Implemented in SparkFun_UBLOX_GNSS::SfeI2C, SparkFun_UBLOX_GNSS::SfeSerial, and SparkFun_UBLOX_GNSS::SfeSPI.

virtual uint8_t SparkFun_UBLOX_GNSS::GNSSDeviceBus::writeBytes ( uint8_t * data,
uint8_t length )
pure virtual

Write a block of bytes out over this bus.

For Serial, this is Serial.write(). For I2C, this pushes the data to register 0xFF in one transmission. For SPI, writing also reads simultaneously, but the read data is discarded here - use writeReadBytes() to keep it.

Parameters
dataPointer to the bytes to write.
lengthNumber of bytes to write.
Returns
The number of bytes actually written (0 on failure).

Implemented in SparkFun_UBLOX_GNSS::SfeI2C, SparkFun_UBLOX_GNSS::SfeSerial, and SparkFun_UBLOX_GNSS::SfeSPI.

Write a block of bytes while simultaneously capturing the bytes read back.

Meaningful for SPI, where every write is inherently also a read. Not applicable for I2C or Serial (their overrides are no-ops that return 0).

Parameters
dataPointer to the bytes to write.
readDataBuffer to receive the bytes read back, same length as 'data'.
lengthNumber of bytes to transfer.
Returns
The number of bytes actually transferred (0 on failure or if not applicable).
