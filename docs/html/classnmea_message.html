Construct a new, unregistered nmeaMessage object.

Leaves every field at its default (no msgId, no field table, no storage allocated). A subclass calls addNMEA() from its own constructor to actually register its identity and metadata - see addNMEA() below.

Destroy this nmeaMessage, freeing any lazily-allocated storage.

Frees _storage and _callbackStorage if they were ever allocated (via initStorage() / initCallbackStorage()). Safe to call even if neither was ever allocated, since each is nullptr until first use.

Register this message's identity, field table and metadata with the base class.

Called once, from the subclass's own constructor, to populate every _* member below with the subclass's message identifier, field table(s) and configuration keys, and to reset all storage pointers and callback bookkeeping to their initial "nothing allocated yet" state.

Parameters
msgIdThe 3-character NMEA message identifier (e.g. "GGA").
messageLengthMaximum message length in bytes (an actual received sentence may be shorter).
numCallbackCopiesNumber of ring-buffer slots to allocate for callback storage.
numFieldsNumber of entries in 'nmeaFields' (header + footer fields only - excludes 'numBlockFields').
nmeaFieldsPointer to this message's own, permanently-lived field table.
msgOutKeysFour UBLOX_CFG_MSGOUT_* keys (I2C, SPI, UART1, UART2) used to enable/disable this message's automatic output.
blockFieldsOptional field table describing one repeated block, for a variable-length message (e.g. NMEA GSV's per-satellite blocks). Defaults to nullptr (no repeated blocks).
numBlockFieldsNumber of entries in 'blockFields'. Defaults to 0.
numHeaderFieldsNumber of header fields before the first repeated block (also the field-table position of the first footer field). Defaults to 0.
maxNumBlocksUpper bound on the number of repeated blocks. Defaults to 0.

Look up one field of this message, by name, in a given NMEA sentence buffer.

Walks the comma-delimited sentence in 'buffer' to find field 'fieldName' and returns its text, converted according to that field's nmeaDataType (see nmeaFieldFormats_t above). Shared core used both for a live/polled read (from this object's own _storage) and for a callback read (from _callbackStorage) - see getNmeaMessageField() and getNmeaMessageBlockField()/getNmeaMessageBlockFieldCallback() in u-blox_GNSS.cpp.

Parameters
bufferThe NMEA sentence bytes to search (this message's _storage, or its _callbackStorage), which must start with '$'.
fieldNameName of the field to find, matched against each entry's fieldName.
valueOut parameter: filled in with the field's text (converted per its data type), or cleared to an empty String on failure.
fieldsOverrideOptional field table to search instead of this object's own _fields - used to search a repeated block's own field table (see _blockFields, e.g. NMEA GSV's per-satellite blocks). Defaults to nullptr (search _fields).
numFieldsOverrideNumber of entries in 'fieldsOverride'; ignored when 'fieldsOverride' is nullptr.
blockIndexWhich repeated block a block-field lookup should read; ignored unless 'fieldsOverride' is given. Defaults to 0.
Returns
true if 'fieldName' was found (and *value filled in); false if 'buffer' is null, malformed, too short, 'blockIndex' is out of range, or the field name was not found.

◆ initStorage()

bool nmeaMessage::initStorage ( void )
inline

Lazily allocate this message's raw payload storage (_storage), if not already done.

Allocates and zero-fills a buffer of _messageLength bytes on first call; subsequent calls are a no-op. This is what lets a message that is never instantiated/used avoid consuming any RAM for its payload - see the class-level comment above for the "delete the header, save the RAM" design intent.

Returns
true if _storage is non-null after the call (already allocated, or successfully allocated now); false if the allocation failed.
